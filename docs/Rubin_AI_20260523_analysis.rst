大摩拆解英伟达Rubin:GPU不再独占蛋糕,Memory、PCB、MLCC、ABF价值集体起飞
---------------------------------------------------------------------------------

大摩这份拆解报告的核心结论是——AI 服务器的价值正在从 GPU 单点爆发，转向系统级全方位升级。Rubin 机架的 780 万美元天价并非由 GPU 独自支撑，而是内存、PCB、MLCC、ABF 基板等外围组件集体价值起飞的结果。

对于供应链投资而言，这意味着不能只看 GPU，更要关注"GPU 之外"的结构性机会。
