随笔168 关于幸福
==============================================================================

得不到的永远在骚动，被偏爱的总会有恃无恐。
------------------------------------------------

早在275年前，孟德斯鸠就写到：“如果你希望自己幸福，这很容易；但是如果你希望自己比别人更幸福，这就很难了，因为我们总是高估别人的幸福”
------------------------------------------------------------------------------------------------


如果有一天你突然觉得自己不太容易生气了，别人说话你也懒得计较了，一天天也没有那么想要证明自己了。晚上想起不愉快的事儿，也不那么焦虑了。你突然感叹，生活好像变轻松了。其实啊生活并没有变轻松，是你在慢慢变好了。
------------------------------------------------------------------------------------------------
