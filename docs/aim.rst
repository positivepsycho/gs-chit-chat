随笔六十五 目标、目的、初心
============================


第一性原理。我们的目标是穿过沼泽地，而不是对付每一条鳄鱼。所有的事情都要以目的和结果为导向，除此之外，其他全部是毫无意义的内耗！！！！
-----------------------------------------------------------------------------------------------------

上班的第一性原理是挣钱，而不是争头牌。或者获取到足够的技能和资金可以不上班，做点别的事情。多盘算盘算如何赎身，而不是争风吃醋上瘾。
-----------------------------------------------------------------------------------------------------

管他什么态度，你把你的事情办了就行。永远以目标为导向，其它的都是无意义的情绪内耗。
-----------------------------------------------------------------------------------------------------

将军赶路，不追小兔。
