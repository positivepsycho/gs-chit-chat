随笔117 动物庄园（乔治奥威尔）
====================================================


《动物庄园》作为经典政治寓言小说，情节围绕一场动物革命的兴起与变质展开，每个关键节点都暗藏对权力异化的隐喻。

1.  **革命前夕：思想启蒙与火种播撒**
    故事始于曼纳庄园，农场主琼斯酗酒懒惰，对动物们肆意剥削。农场中德高望重的老年公猪老少校召集所有动物开会，它在会上痛斥人类是不劳而获的寄生虫，控诉动物们辛勤劳作的成果被人类掠夺，最终还难逃被屠宰的命运。随后老少校传授了《英格兰深处之歌》，歌曲描绘了无人类压迫的动物天堂，点燃了动物们反抗的热情。三天后老少校在睡梦中离世，公猪拿破仑、雪球和尖喇叭将其思想整理为“动物主义”，成为革命的指导理念。

2.  **奋起反抗：建立理想庄园**
    一次琼斯因醉酒忘记给动物喂食，忍无可忍的动物们终于爆发，集体冲向人类并将他们赶出了庄园。动物们将庄园更名为“动物庄园”，还制定了写在谷仓墙上的“七诫”作为宪法，核心是“所有动物一律平等”“两条腿走路的都是敌人”等。起初庄园呈现出蓬勃生机，首次收获创下历史新高，动物们为自己劳动充满动力。猪因智商高担任管理者，雪球积极教动物们读书识字，而拿破仑则悄悄抱走了几条小狗，声称要亲自培养。同时猪群还独占了农场里的牛奶和苹果，理由是自身承担管理重任需要补充营养。

3.  **权力角逐：领袖反目与独裁初现**
    琼斯联合其他农场主发起反攻，雪球凭借出色的战术指挥动物们打赢了这场“牛棚战役”，声望大增。之后雪球提出建造风车，以此改善庄园设施、减轻动物劳作负担，却遭到拿破仑的坚决反对。在讨论风车提案的大会上，拿破仑突然放出已被训练成爪牙的九条恶犬，将雪球驱逐出庄园。随后拿破仑宣布由猪群独揽决策权，还改口称风车计划本是自己的构想，只是被雪球剽窃，以此拉拢动物们的信任。

4.  **独裁深化：戒律崩坏与血腥清洗**
    拿破仑掌权后，动物们开始了艰辛的风车建造工作。忠心耿耿的马鲍克瑟始终以“我要更努力工作”为信条，承担了最繁重的劳动。期间风车曾被暴风雨摧毁，拿破仑却谎称是雪球潜回庄园破坏，借此煽动动物们对雪球的敌视。为巩固独裁，拿破仑还策划了血腥清洗，逼迫一些动物虚假“认罪”与雪球勾结，随后让恶犬当众咬死它们。与此同时，“七诫”被不断篡改：猪搬进琼斯的房子睡床，就将“禁止睡床”改为“禁止睡带被褥的床”；猪开始饮酒，便把“禁止饮酒”改成“禁止过量饮酒”，动物们虽有疑虑，却被巧舌如簧的尖喇叭强行说服。

5.  **彻底蜕变：回归压迫与理想破灭**
    随着时间推移，猪群的特权愈发膨胀。它们不仅穿起人类的衣服，还与周边农场主开展贸易，甚至参与赌博。鲍克瑟因过度劳累倒下后，拿破仑没有兑现为它养老的承诺，反而将其卖给屠马商，之后对外谎称它是在医院救治无效离世。最终，“七诫”被彻底抹去，只留下一句荒诞的标语：“所有动物一律平等，但有些动物比其他动物更为平等”。动物庄园的名字被改回最初的曼纳庄园，当其他动物透过窗户看到猪与人类举杯共饮、谈笑风生时，已然分不清彼此的区别。曾经为自由而战的革命，最终让动物们陷入了比以往更黑暗的压迫之中。
