随笔201 AI泡沫什么时候破裂？标准答案
================================================

AI泡沫什么时候破裂？这个问题是有标准答案的。
------------------------------------------

历史反复证明，泡沫从来不会内爆，只会被外力刺破。
------------------------------------------------------

我们要做的就是破裂之前咬牙拿住，破裂之时果断逃跑，这就是泡沫游戏的玩法。
----------------------------------------------------------------------------

所以关键点就是找到泡沫破裂的时间点。
----------------------------------------------------------------------------

现在的科技主线有没有泡沫？当然有，但是有泡沫它照样能继续涨，泡沫是可以越吹越大的，它大到什么程度会内爆呢？答案是永远不会内爆，只能被外力刺破。无论是股市的案例还是房地产市场的案例，都在证明这一点。

2000年互联网泡沫是怎么破的，不是因为股价太贵，股价贵了还能更贵，估值倍数标到天上还能继续标，不要指望它涨不动，它总能涨得动。 这场泡沫是从外部刺破的那就是美联储加息。

1999年6月，美联储开始加息，一直加到2000年5月，累计加息175个基点的时候，纳斯达克见顶开始崩盘。 

A股10年前的一场超级大牛市，还记得吗？当年为什么涨得那么疯狂？因为当时场内融资和场外配资非常宽松，股市一涨，更多的投资者借钱进场，推动股市继续涨。

转折点是什么？是监管出手，切断杠杆。 2015年6月12日，证监会公布限制杠杆的规则草案，泡沫当天立刻破裂，杠杆资金踩踏式出逃。股市是这样，

房地产市场也是这样，早在2016年就有一大堆人海。 房价有泡沫不要再买了，但是它继续大涨，直到21年才转折。

为什么这时候转折？因为20年8月出台了三道什么线啊，严控房地产企业杠杆率。

美国08年金融危机爆发是房地产泡沫破裂引爆的，房地产泡沫怎么破裂的？ 也是美联储加息，04年6月开始连续加息。06年7月房价见顶，泡沫破裂。

日本1990年房地产泡沫破裂，也是因为日本央行加息，89年5月开始加息，89年12月股市见顶，90年土地价格见顶。

这背后的逻辑是什么？为什么资产泡沫可以自我维持，越吹越大，却不会内爆。为什么只有外力才能刺破它？

明斯基的金融不稳定假说专门研究了泡沫问题。
-------------------------------------------------

泡沫看起来是一个价格不断上升的现象，实际上它是一台融资机器，无论是股价还是房价，它越涨，投资者越想去追涨，它越涨，股票的房子拿去抵押之后，借到的钱就越多。

这些钱又重新回到市场里继续推高资产价格，这是一个自我维持自我强化的循环。

不止这一个循环啊，股市越涨，企业增发股票发行债券就越容易，容纳的这些钱再拿去大笔投资，扩大业务，业务越大，反过来又推动股价上涨。

今天的AI泡沫和当年的互联网泡沫都是这样的，房价越涨，开发商就越能向银行借钱。这些钱再拿去进一步买地，炒高地价，推高房价，这也是一个自我强化的融资循环。

在没有外力介入的情况下，融资循环可以持续运转，资产价格可以推到非常荒谬的地步，不要指望它内报，它几乎不可能内爆，不要指望融资循环转不动，它几乎不可能转不动。

真正的转折点永远是外力的介入。
---------------------------

要么是央行加息，要么是监管政策，这些外力的本质都是同一件事情。

切断融资链条，切断融资循环，加息会抬高债务成本，加的越狠，融资滚得越慢，最后滚不下去。

一旦滚不下去，这个自我强化的循环就会转变为自我毁灭的循环。

由于融资条件收紧，有一批人不得不强制卖出，引发价格下跌。下跌之后，抵押品价值缩水，造成账面损失。

如果是股票的话，不得不强制平仓，被迫卖出。

如果是房子的话，那就是借款人断供，银行收回并且卖出，所有的正循环都变成负循环，导致连锁式的价格崩盘。

难道所有泡沫破裂都是因为外力吗？有没有返利呢？没有外力介入他自己内曝了，还真有反例。

1637年，荷兰郁金香泡沫的破裂，不是央行加息，也不是政府监管，它就是市场内部突然没有买家了。

因为价格太高了，导致最后一批接盘者消失了。这个例子很经典，但是内爆的例子还是非常稀少。

我们熟知的这几场泡沫破裂都是因为外力。所以我们现在面对的AI泡沫什么时候破裂呢？ 核心关注点就是美联储加息或者缩表，这两招都会收紧融资链条，抑制杠杆资金进入股市，抑制AI企业大规模投资本开支。

但是并不是说美联储一加息，泡沫立刻就破裂，他往往需要连续多次的加息，用几个月时间把融资链越收越紧，紧到转不动才是泡沫破裂点。
