随笔123 蔡澜的悟(睡后收入/属于你自己的游戏)
==========================================================


1，别老根11点出门的人混，出卖时间有上限，没前途。富人：谈项目，整合资源，对接关系，踩风口。

2，想年赚100万，就别死磕10万的事。有些赛道和岗位天然有天花板。

3，停止卖命，开始造资产。睡后收入。

一本书，一个版权；

一个课，一个品牌；

一个程序，一个系统；

一个不用你天天盯着，就能进账的管道；


蔡澜的实践：辞掉影视公司助理工作，转向产生被动收入的领域——写书（畅销书版权收入超8位数）、做美食品牌（连锁门店带来稳定收入），最终实现财富自由。 圈子的重要性：远离局限思维的圈子，接近能提供资源、信息和机会的圈层，潜移默化中提升认知。 赛道的关键：摆脱“卖时间换钱”的模式，构建被动收入资产（如内容创作、品牌运营、管道搭建），让收入脱离时间限制。 行动的力量：即使没有具体操作方法，明确方向后及时调整，通过实践（如蔡澜写书、开店）逐步摸索，最终实现目标。 蔡澜强调，这两句话彻底改变了他的赚钱思路，先换圈子开阔眼界，再换赛道构建被动收入，才从“为月薪熬夜加班”转变为“财富自由后享受生活”。

-----------------------------------------------------------------------------------------------------------------------------

最近我们公司来了一批某大厂工程师，降薪也要来，原因是加班太太太严重了，他们加班严重到什么程度呢？就是研发是要上夜班的，要两班倒。然后我就问他们说，现在还有什么样的行业，有这么多项目啊，他们说一年其实就一个项目是给美国人做的，他们事儿多，我第一反应是觉得细思极恐，我想到了一个词儿。

知识产权殖民，因为我们公司也做海外项目，客户要求极多极高，反复变动。

而且他要求你的每个技术原理都要给他讲的明明白白的。因为他们想做创新。创新呢就需要大量的验证，所以他们就想借助别人的脑力、体力和时间去打磨他的创意，去试错，最终成就一个属于他们的完美的商品。

那这个事儿谁能做的又快又好呢？中国人。我们聪明特别的拼，我们是能打硬仗的，劳动力也便宜，就是再难的题。只要你出了。 我们就有人能拿100分，
我们就有这种解决问题的能力。

那欧美企业有一个很大的优点，就是他们愿意支付研发费。而且是一笔可观的研发费，我们也很需要这笔钱，因为它会很大程度上让我们喘口气儿，或者提高团队的待遇。

当然，问题也在这儿，因为支付研发费就意味着知识产权要属于他们。这其中就包括了很多我们熬夜功课的技术难题，或者反复验证的工艺细节等等。某种程度上我们有点像世界创新的高级苦力，替人做嫁衣。有可能会两手空空，

但是如果你不做，你会发现后面有无数的同行在等着当接盘侠，所以这个事儿是无法避免的那你可能就会问了。我们干嘛不自己做创新呢？你们要知道创新是奢侈品。一个企业还在为了生存挣扎，我们作为打工人，不得不用熬夜去透支健康的时候，谁还有余力去赌一个不确定的未来呢？帮别人解决问题，一定可以拿到钱。

但是大部分的创新是你钱花出去，连点水花都没有的，创新它很难。我做工业设计的时候感受尤其深，就是产品往往是两极分化的。

一类是极具创新，但只能到样品阶段的吉祥物放在那里当公司门面的，还有一类是为成本让路的低利润的商品。而且你其实很少会在同一家公司。同时看到这两类产品，所以大部分工业设计师会纠结于理想和现实之间，最终选择的是转行。

那我们普通人的出路在哪儿呢？聊一聊我自己的看法，我觉得未来属于小而没。你看现在很多人做自媒体，做独立技术分享，做某个领域的资深顾问，或者你自己门手艺。比如能修高端设备，专精某一类人群的职业规划等等吧。就是抓住一个细分领域，然后扎下去，持续输出你的专业，你的见解，你的解决方案。

把它做到极致，直到成为这个领域的王者。这件事的关键在于专注和深度，就是你只要做的足够深，那信任你的人群就越精准。大家遇到问题的时候，第一个想到的就是你。

这个就是我们常说的核心竞争力。这时候你的价值或者你的身份就变了，你不是一个可以被随意替换的，只能通过加班啊或者压价呀来竞争的劳动力，而是成为了一个具有特定价值的问题解决者。同时你吸引来的是认可你专业，愿意为这份专注付费的人，

其实就是在积累你自己的知识产权，或者说建立个人IP他可能不会让你一夜暴富。但它能给你带来的是健康的收入模式和自主的工作节奏，以及最关键的那一部分对自己时间和成果的掌控感。因为你足够专业，足够稀缺，所以你不必再为别人的梦想铺路。你可以定义属于你自己的规则，属于你自己的游戏。
