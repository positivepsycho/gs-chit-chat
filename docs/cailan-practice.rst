随笔123 蔡澜的悟(睡后收入)
==========================================================


1，别老根11点出门的人混，出卖时间有上限，没前途。富人：谈项目，整合资源，对接关系，踩风口。

2，想年赚100万，就别死磕10万的事。有些赛道和岗位天然有天花板。

3，停止卖命，开始造资产。睡后收入。

一本书，一个版权；

一个课，一个品牌；

一个程序，一个系统；

一个不用你天天盯着，就能进账的管道；



蔡澜的实践：辞掉影视公司助理工作，转向产生被动收入的领域——写书（畅销书版权收入超8位数）、做美食品牌（连锁门店带来稳定收入），最终实现财富自由。 圈子的重要性：远离局限思维的圈子，接近能提供资源、信息和机会的圈层，潜移默化中提升认知。 赛道的关键：摆脱“卖时间换钱”的模式，构建被动收入资产（如内容创作、品牌运营、管道搭建），让收入脱离时间限制。 行动的力量：即使没有具体操作方法，明确方向后及时调整，通过实践（如蔡澜写书、开店）逐步摸索，最终实现目标。 蔡澜强调，这两句话彻底改变了他的赚钱思路，先换圈子开阔眼界，再换赛道构建被动收入，才从“为月薪熬夜加班”转变为“财富自由后享受生活”。
