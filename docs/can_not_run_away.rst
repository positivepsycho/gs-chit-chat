随笔144 做任何事情不要后视镜(后视镜就是接盘)+但凡你跑不脱的，反而是要投的（薛松）
===========================================================================


散户化的票不要碰（股东人数历史新高）。散户的投资方式是什么便宜买什么。但是，如果一个公司或者一个行业靠谱，从最低点起来30%或者50%，并没有透支未来，反而是方向的确立。

------------------------------------------------------------------------

先问哪里你跑不脱，但凡那你跑不脱的，反过来就是人家挣钱的，反而就是你要投的。--薛松

例如，你的生活可以离开拼多多，京东，阿里这些吗？你能逃掉证券公司从你身上挣钱吗？

做任何事情不要后视镜，已经有人得利了，然后你再去模仿这个操作，就是后视镜。--薛松

------------------------------------------------------------------------


股息是分红和股价共同决定的，就是分子和分母的关系，银行股已经上涨了，股息就降低了。

例如，银行股已经涨了几倍了，你说我现在去吃股息，就是后视镜，三年前你干啥去了。

后视镜就是后知后觉，就是接盘
