随笔122 陈小群和他的游戏规则
===========================================================

陈小群的操作风格以“情绪周期+龙头战法+极致纪律”为核心 ，结合严格的纪律与市场情绪研判，形成了一套高胜率的短线战法，他偏好的股票通常位于热门题材的中心位置
---------------------------------------------------------------------------

陈小群，本名陈宴群，大连人，1995年出生，是新生代游资代表之一 。

陈小群大学期间就开始接触股市 ，2018年，他以30万元本金入市，通过打板、低吸、套利积累经验，执行严格的止损纪律——单笔亏损超过5%即强制离场。

2022年，他的资金首次突破亿元大关，通过反复参与市场的“龙头战法”实现爆发性增长。2024年12月期间大手笔参与了多只热门概念股的交易，12月19日，陈小群卖出粤传媒超过6100万元，次日该股即出现一字跌停的情况。2025年1月，陈小群在社交平台上表示计划转型为价值投资者，关注中长线布局。然而，转型初期即遭遇约2000万元的亏损。同年8月，陈小群在朋友圈公布实现“十倍”收益。2026年1月，在朋友圈发文，一年三个月收益20倍，捐赠10000000元给予中国青少年发展基金会。

陈小群的操作风格以“情绪周期+龙头战法+极致纪律”为核心 ，结合严格的纪律与市场情绪研判，形成了一套高胜率的短线战法，他偏好的股票通常位于热门题材的中心位置，商业航天、AI芯片、能源主线，而且总能在情绪拐点上精准出击。自2024年9月24日至2025年12月25日期间，陈小群的常用席位中国银河证券大连黄河路一共曾出现在152只个股的龙虎榜单上，龙虎榜累计成交金额高达360.49亿元。
