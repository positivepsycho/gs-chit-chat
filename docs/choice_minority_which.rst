随笔142 要过上少数人的人生，就必须有少数人才有的勇气，做少数人才敢做的选择
===================================================================================


生活当中最大的悖论就是人们总是选择大多数人选择的选择，但是期待一个超过大多数人生活的结果。
-------------------------------------------------------------------------------------------------------

丹麦哲学家克尔凯波尔说：大多数人在随波逐流，是因为随波逐流很安全，人天生害怕选择，害怕无聊，害怕孤独。

所以人类永远只有很少的一部分人去做选择，他们拒绝随大流。 

他们要独自去对抗无聊，去承受孤独。

许多人都习惯随大流的时候，就必然会出现一个现象。就是很多人追求的东西都不是自己需要的。 

而是因为别人都有了。比如说你真的需要大房子吗？还是觉得到了年纪该有大房子的，或者因为大家都有了，你真的需要结婚吗？还是你的价值观需要你结婚，还是因为大家都结婚了。 所以他说大家用时间和生命去兑换的很多东西，也许并不是自己真正需要的，而是因为他们都有了，大家都有了。

-------------------------------------------------------------------------------------------------------


我们不相信那些被历代人验证过的经验，比如热爱、勇气、自由和决心。觉得那些太理想主义，转身挤进那个所谓现实的被迫的赛道里面。

我们选的是安稳，是保险，是标准答案，但是渴望的却是独特，是精彩，是脱颖而出。

逻辑的反面往往才是真相。

如果你想过一个讨巧的人生，想要一个看起来被世界偏爱的人生，那么你首先就要理清这个最基本的逻辑。如果想要过上少数人的人生，你就必须先有勇去做少数人的选择。

这不是鼓励叛逆，而是认清一个简单的现实，没有犯错的人生，恰恰是最错误的人生。

因为你把那颗鲜活的充满可能性的心锁进了一个绝对安全的保险箱，它不会破碎，但是也从未真正的跳动过。避免所有风险的唯一方法就是避免所有成长。

我们好像总是在害怕犯错，害怕一步踏错，满盘皆输。

但是你想过吗？安全区才是最危险的冒险，因为它偷走了你人生所有的可能性。那些过度追求完美，履历上找不到一次愚蠢决定的人，很可能从来没有真正为自己活过。

因为真正可怕的不是做错了，而是没有做过。前者至少积累了经验，但是后者只留下了空白。所以我想对你说，也想对我自己说，不要怕，我们好像总是在焦虑焦虑选错专业，选错工作，选错伴侣，焦虑某一步踏不准节奏。

不要怕好吗？现在可能经济比较动荡，但是应对外部动荡的解法就是你比他还动荡。现在是探索自我的代价最小的时候。

如果大船要沉，那么所有人都是在泰坦尼克号上选座位，结果都一样，焦虑也没有用。

如果大船最终会乘风破浪，那么最后赢的人就是在这段时间仍然坚持的人。
