注意啊：一定是要先进封装，不要落后的封装，要能解决未来芯片能力提升的封装。

目前影响高端芯片产能最大的瓶颈已经到了封测这一块了。而封测可以说全球的50%以上的产能都是我们国内的，就是海峡两岸加一起超过50%的产能。

所以在这种情况下，其实这个利好这个逻辑是非常之清晰的，有业绩做支撑，且产能我们占大头。

所以在这种情况下，即便行情下跌的话，也不用太担心有业绩支撑的方向，它不怕下跌。

他怕的是什么？怕的是持续往上去走，不给回调的机会。所以关于封测这条线，大家可以多去观察一下。
