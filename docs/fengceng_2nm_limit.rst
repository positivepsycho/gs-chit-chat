米磊：中国新一轮科技崛起一定靠光子

现在北大的校长是搞光学的，清华的校长是搞光学的，港大的校长是搞光学的，包括连西电现在都调了一个搞光学的去当校长了。每一个大国崛起都是靠新一轮科技革命，英国是靠机械，美国靠电子，中国一定是依靠光子，英特尔、IBM, 华为啊，思科全部在收购光芯片公司，包括英特尔成立了集成光子学研究中心，台积电宣布和英伟达联手搞光芯片，就是这也是一个很明确的这个趋势了。

为什么光子比电子有优势呢？啊，这是从物理特性来决定的，它可以超高速低功耗的这种特点，光子它性能可以提升1000倍，功耗会降低很多倍。所以人工智能时代就是从信息的获取、传输、计算、存储、显示，现在都是要从电子到光子啊，比如说信息的获取就是激光雷达，3D传感，信息的传输就是本身就是光通信处理，就是未来是光计算，量子计算，包括现在的显示都是AR/VR、麦克尔、ad, 全是光学，苹果最新出的。

MMR眼镜里面光学成本占了50%，为了推动光子，我们建了一个很大的一个平台去支撑我们光子产业的发展，从第三代半导体到三五足化合物半导体到硅光的平台，我们都在做啊，也孵化了一批的非常优质的企业，包括淘金量子，塞福勒斯啊这样的这个光芯片的企业，那下一步呢，我们在推动硅光的这个平台的建设啊，用在这个数据中心啊，5g啊，自动驾驶，ARVR啊，然后包括苹果手表，二五年就会推出血糖仪的检测，都是用硅光的芯片来做，所以它的这个市场是非常非常大的。
