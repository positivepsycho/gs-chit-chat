随笔183 蒋宇飞：四条大鱼，三条小虾
===============================================

四条大鱼（芯/gpu/cpu，光，存，叠/cowos/copos），三条小虾（mlcc, 玻璃基板，abf）
---------------------------------------------------------------------------

堆叠（HBM、cowos/copos）引爆了什么：1，设备和材料消耗是传统封装的5-10倍，2，玻璃基板。3，测试，在堆叠中成本占到30%甚至更高。
------------------------------------------------------------------------------------------------------------------------------------------------

非线性增长：哪一种存储距离GPU最近，哪一种存储的空间就最大（HBM到HBF）。
----------------------------------------------------------------------------------------------------------

鼎泰高科的非线性增长，本质是AI 服务器 PCB 层数 / 孔密度飙升→钻针更细、长径比更大→单孔损耗暴增、寿命断崖式下滑→耗材需求非线性爆发。AI 产业链里，凡是 “技术规格抬升→单台用量 / 损耗指数级增长→供需持续紧张”的环节，都在复制这个逻辑。
那么，随着cowos和copos的继续发展，以及堆叠的进一步推进，钻针会更细，更长，但是也更不现实。
那么，是不是后续就是要用激光来打孔，
同理，后续晶圆的划片是不是也需要激光来切割，不然应力不均匀，引起碎裂。

----------------------------------------------------------------------------------------------------------------------------

蒋宇飞创投论的观点:2026年下半年到2028年，A股重点关注“芯、光、存、叠”四条大鱼和“MLCC、ABF、玻璃基板”三只小虾，白酒、旅游、建材等其他赛道不用看。
-----------------------------------------------------------------------------------------------------------------

芯是主芯片，GPU持续紧缺是AI牛市原点，CPU因Agent需求开始短缺，国内龙头已达八千亿市值，未来还会涨，CPU像博士做复杂计算，GPU像一万个小学生做简单重复计算;光指光模块，贯穿这两年行情，供应紧张订单排到明年，但全球规模400亿美元，国内龙头占30%+，上游芯片非国产，增幅有限利润会兑现价格趋降;存是存储芯片，行业景气度高，短期小回调不影响长期前景;叠是CoWoS先进封装堆叠，未来十年最大赛道，规模有望达千亿美金超过光模块，核心是存算一体解决AI算力瓶颈。三只小虾初期是小赛道，后面会长大。投资要重仓芯光存叠，偏离主线难有收益，科技创富时代看懂这四个赛道，未来三年聚焦主线就能“赢在重注时刻”。
