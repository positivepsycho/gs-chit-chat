随笔183 四条大鱼，三条小虾
===============================================

四条大鱼（芯/gpu/cpu，光，存，叠/cowos/copos），三条小虾（mlcc, 玻璃基板，abf）
---------------------------------------------------------------------------

堆叠（HBM、cowos/copos）引爆了什么：1，设备和材料消耗是传统封装的5-10倍，2，玻璃基板。3，测试，在堆叠中成本占到30%甚至更高。
------------------------------------------------------------------------------------------------------------------------------------------------

非线性增长：哪一种存储距离GPU最近，哪一种存储的空间就最大（HBM到HBF）。
----------------------------------------------------------------------------------------------------------

鼎泰高科的非线性增长，本质是AI 服务器 PCB 层数 / 孔密度飙升→钻针更细、长径比更大→单孔损耗暴增、寿命断崖式下滑→耗材需求非线性爆发。AI 产业链里，凡是 “技术规格抬升→单台用量 / 损耗指数级增长→供需持续紧张”的环节，都在复制这个逻辑。
那么，随着cowos和copos的继续发展，以及堆叠的进一步推进，钻针会更细，更长，但是也更不现实。
那么，是不是后续就是要用激光来打孔，
同理，后续晶圆的划片是不是也需要激光来切割，不然应力不均匀，引起碎裂。
