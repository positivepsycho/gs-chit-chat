这部片子直接就把矛头指向了他的老师。当年传授。给他们的那套技术。在这部片子大火之后呢，folk的研究方向就转型了，

他正搞清楚了不在是如何让人对产品上瘾，而是如何让人培养对自己有益的习惯。他把20多年的研究成果总结成了一本书，叫做弗格行为模型。

这本书帮我们解释了一个根本问题。就是为什么我们总是想改变自己，但却总是在改变自己上失败呢？ 其实它不是自律的问题，也不是动机的问题，更不是意志力的问题。而是一个方法论的问题。

今天我们就来拆解书里面最经典的模型。B等于map，这是让任何一个好行为持续发生的底层逻辑。我们先来看这个公式里的几个字母究竟代表些什么？这个公式是B等于M乘A乘PB是bevior，就是行为M是mo。动机Aability能力P是pro就是提示，就是有没有人或者东西或者外界的任何物体去提醒这个人去做这件事情。

注意哦，这里是惩罚，这就意味着只要任何一项是零，这个行为就不会发生。

比如说你想健身，你这个念想就是M值，健身房就在楼下它很容易去，这是A值很高，但是没有人提醒你做这个。所以P值是0，所以最终结果大概率是你不会去这个健身房去坚持这个健身。

fg有一个非常核心的洞察，就是动机M是这个世界上最不可靠的东西。这个判断是有数据支撑的。

美国很早的时候有一个运动app，它这个平台上又有9500万个用户，美国总共才3亿人，这是非常非常大的体量。他们分析了用户数据之后发现美。年1月的第二周，用户的运动量就会出现大幅度的下跌。也就是说，这一周，大量人群从每天去跑步，去健身房突然停了下来，

他们还为此特意给这个现象取了个名字，叫做cter day，中文名叫放弃日。美国的福布斯健康调查也给出了一个更残酷的数据。他们调查了1000名美国的
成年人发现这些人的新年。

决心也就是新年开年的时候，立的flag平均只能坚持3.74个月，最终只有6%的人能坚持超过一年。

我们新年的第一天总会给自己做各种的开年展望的。所有人的动机在那一天都会是100分。但问题是这个100分维持不了14天。folk说，既然M靠不住，
那我们就可以把另外两项做到极致。

具体。怎么去做呢？首先第一招就是把A值拉满，把这个行为小到轻而易举就能做到。就说你要想坚持健身的话，你不是每天要做30个俯卧撑啊，你先把手撑到地面上去做出来。

第一个，你要想读书，你不是说么每天去读30页书，你就先翻开书本去看第一行字，这样子有两个好处。

首先启动一件事的时候，大脑能量消耗最大。的是在第一步，一旦这个启动完成了，人们就会因为蔡迦尼克效应而继续坚持下去。这个效应来自苏联的心理学家blueman zeric1927年的实验，他发现人们对未完成的事情，记忆的强度是已经完成事情的两倍。

所有已经开始，但还没完成的事情会像一根刺一样卡在人类的大脑里催着你去完成它。所以。你只要先把手撑在地面上，大脑就会开始烦你，他会跟你说，你既然趴下去了，那先做两个俯卧撑再说吧。

第二个好处是，一旦我们每天都能完成那个轻而易举的目标之后，我们的大脑就会强化一个信念，它就会自动跟你说，你是一个会坚持的人。

关于这一点了，我们以前提到的原子习惯这本书里面有一个跟fog的观点不谋而合的事情。就是他说真正持久的改变不是目标导向，而是身份导向的改变。
就是比如我们要减肥。我们不要说我们减10斤还是20斤，我们要告诉自己，我是一个会照顾自己身体的人。

比如我们要读书。我们不要说我们要读完这本书那本书，而是我们要告诉自己，我就是一个热爱学习的人，

我就是每天会坚持读书。而这个身份是怎么来的呢？就是被我们每天的行为一票一票喂养出来。讲完了A纸，我们讲第二个P制。我们去把P质拉马要做。什么事情呢？folk对于提示的方法就是不要给自己设闹钟，不要给自己贴便利贴，或者用什么APP的提醒。

他觉得这些都不可靠。他觉得真正可靠的事情是你自己正在做的事情。也就是在已经有习惯之后，我们会进行的新的小行为。

他把这个方法叫做锚点法。比如说他本人在视频开头提到的，他上完厕所之后就做两个。程比如我要坚持读书，那当我坐下喝早上第一杯咖啡的时候，
我就开始翻开说读他的一眼。

这个方法最精妙的地方就是在于我不需要去记住做这件事情。因为你已经有的习惯本身就是一个题型，除了A跟P之外，folk还提到一件事情叫做庆祝，这是整本书里面最被低估的一步。

前面的A值跟P值很多习惯类的书里面都讲。但是有一招是fok独有的，也是他最新最骄傲的发现。

就是你做完那一个习惯性的小动作以后，立刻开始为自己庆祝。就比如他本人在上完厕所，做完两个俯卧撑之后，他就开始鼓励自己，你干的漂亮，这听起来很尬，对吧？很多人会觉得自己是个成年人，做完两个俯卧撑还要给自己鼓掌，是什么意思呢？ 我觉得太羞耻了，但事实上不是这样，folk就说，

如果你只能从这本书里面拿走一件事，请拿走庆祝这件事，为什么呢？因为情绪才是真正把行为刻进你大脑里面的东西。这件事情在1990年代就被剑桥大学的神经科学家郭 shorttz用一个经典的实验验证过，他给猴子设计了一个简单的任务。

如果这个笼子里面的信号灯亮起。猴子按下这个按钮，他就能喝到一口苹果汁。然后这个教授就用电籍记录了猴子大脑里多巴胺神经元的活动。
一开始猴子还没有掌握这个规律的时候，他的神经元只会在喝到苹果汁的那一刻开始放电。

后面猴子学会了，看到信号灯亮起就会按按钮，然后他就能喝到果汁。他一学会这一整个完整链条之后，惊人的事情就发生了，就是观察到猴子的。神经元放电时机，从喝到苹果汁的瞬间，提前到了信号灯亮起的瞬间。

也就是说，当猴子习惯这个链路之后，光看到信号灯，他的多巴胺就先释放出来了。这个机制完美解释了为什么fog的庆祝是有效的。

就当fog本人做完上完厕所，就做两个俯卧撑，然后就为自己庆祝这个行为之后，庆祝带来的这个积极情绪就会。激活他多巴胺的神经元，然后让他的大脑得出一个结论，就是做完俯卧撑这个行为之后，自己的大脑就会被多巴胺奖赏。

然后当fog重复了无数次这个行为之后，他上完厕所，这个信号一出现，他的大脑就会自动期待那个庆祝的爽感，

然后开始主动催他去做俯卧撑。就会到这里，fog的福歌行为模型这本书里面的核心内容就给大家拆解完。所以说，真正坚持下来的事情，从来不是硬撑下来的坚持，而是被我们设计出来的坚持。

就像我们手机里那些让我们成瘾的app。也是经过不同的产品经理精心设计出来的一样。所以说如何让一件事真正坚持下来，

答案就是三招。第一就是把行动砍到绝对不可能失败，然后把这个行为挂在我们已经有的习惯之后，然后整条链路做完之后为我们自己庆祝一下。这三件事情总共加起来不会超过30秒。但是这三件事情我会用30天、300天3000天，把一个完全不一样的，你慢慢。
