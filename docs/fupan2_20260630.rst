随笔249 复盘2（20260630）善战者无赫赫之功
=================================================================

如果押对了赛道，也赚了不少钱，及时获利了结。抹干吃净的想法不能有，逃顶的想法不能有。
---------------------------------------------------------------------------------------

巴菲特 资产1566亿美元。巴菲特名言：如果你懂投资，你不需要杠杆，如果你不懂投资，你更不应该用杠杆
---------------------------------------------------------------------------------------



所有炒股冠军最终都会破产。这就是真相。

包括总舵主。只不过他破产的方式不同。

因为冠军必然是用了极端的方法，股市收益过程是典型的“乘法”过程，就是说你的乘数里面只要有一个0，那结果就瞬间归零。

所以股市是最能反应“善战者无赫赫之功”的。

实际上这句话的应用场景是战场，本质上股市就是一个战场。

刘邦和项羽楚汉争霸，项羽就是那个每次都赢的人，他就是炒股冠军，每个局部战争都赢。

而刘邦是那个每个局部都尽量控制不出现0的人。

换句话说，如果炒股大赛时间足够长，最终的冠军一定是保守投资者。而非能在短期内夺冠的。

不过最厉害的还是气运之子，先快速赢，再变成守城人。一切努力在气运和天赋面前都不值一提。
