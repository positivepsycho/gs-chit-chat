随笔205 历史上的K型分化是如何演绎的
================================================================

K型分化核心定义:危机后经济、人群、资产走出两条反向曲线：富人/龙头/核心资产上行，低收入/传统中小行业下行，阶层撕裂。

三大经典历史演绎

## 1. 1929大萧条（初代极致K型）

1. 前置基础：20年代财富高度集中，农业、蓝领长期疲软

2. 上行端：垄断大企业、金融资本低价抄底股权地产，兼并小企业扩份额

3. 下行端：农民破产、工人大规模失业，中产跌落底层

4. 收尾：贫富差距触顶，新政加富人税、劳工保障才缓解分化

## 2. 2008次贷危机（金融放水驱动K型）

1. 下行端：刚需购房者断供、传统实体倒闭、工薪收入缩水

2. 上行端：QE释放廉价资金，高净值人群抄底优质房产、蓝筹股权

3. 核心特征：政策托举金融资产，形成“资产涨、劳动收入跌”分化

## 3. 2020新冠疫情（K型概念正式定名）

1. 上行赛道：线上互联网、半导体、医药龙头；持股、持核心房产高收入群体

2. 下行赛道：餐饮、文旅、线下零售、低端服务业；临时工、个体商户

3. 放大因素：全球大宽松，流动性只利好资产持有者，劳务人群无缓冲

# 三、国内两轮结构性K分化

1. 2014-2015：股市、一线房价走强；传统工业、三四线楼市、蓝领承压

2. 2020后：高端制造、头部科技、核心房产走强；教培、线下实体、地产中下游走弱

# 四、历史通用演绎规律

1. 触发：战争、瘟疫、债务危机等外部冲击，先冲击劳动收入与线下实体

2. 放大：货币宽松，资金涌入金融资产，仅利好有产阶层

3. 分层逻辑：轻资产龙头抗风险受益，线下中小微持续收缩

4. 结果：危机同步受损，修复期两极反向走，贫富差距扩大

5. 收敛条件：高资本税转移补贴、扶持实体提高劳动收入，否则分化长期固化

# 五、复苏形态区分

- V/U/L：整体同步复苏，仅快慢差异，无两极反向

- K：一部分持续繁荣，一部分持续萧条，结构性撕裂
