随笔153 轻资产人生
========================================================================

坚持轻资产，抛弃所有权，拥抱使用权，保持高流动性，再用钱生钱。
-------------------------------------------------------------


所有能租的东西一律不买，所有权就是你最大的负债。

这是我最近体会最深的一句话，人都是会死的。

我们这辈子所需要的所有的东西都是生不带来死不带去的。

你真正所需要的只是它的功能和体验，那你就只需要它的使用权就可以了。

一旦你想占有，就会产生很多的债务和风险。不光是车子房子，你要带着万物皆可租的心态来面对生活中的一切。

你看明星很有钱吧，他们每次出席重要的场合，所需要的服装配饰，也都是租来的，房子就不用多说了，大家都懂，每个人都在经历着，车子也是一样。

我每年也只有出去旅游，那个把月会开，其他时间都是僵尸车，放在那不开两个月就亏电。

就算不开，你照样需要保养买保险，真不如用的时候租车来的实在。

同样的理念，我把它用到了生意上，有些工作是可以外包出去的，不是非得请员工的。虽然不是所有的生意都适合，但是你比如那些重复性很高，又特别耗时间的工作就可以外包出去。请员工，你会多出一堆的成本。培训工资、更大的办公室设备、房租、水电等等。

但是生意他是有旺季有淡季的。你旺季还好，淡季的时候，这可是一笔不小的开支啊，所以我就干脆不请人了。淡季的时候一个人就可以，无非就是挤压点睡眠时间。

旺季的时候，我就找几个同行业的代理，这些人还都是老手，也不用培训，也没有底薪，多劳多得，他们反而会更卖力。

那既然是一个人在家办公就可以呀，办公室都省了，投入产出比贼高。

你看那些很牛的人，他们都懂得把一切不擅长的事情都外包出去，他可以租别人的时间精力，可以租别人的智慧，把自己的时间精力都省出来，做自己擅长的更有优势的领域。

所以不管我们是想赚钱的，还是想安稳过日子的，你就记住一条铁律，所有能租的东西一律不买。在这个充满不确定性的时代，我们普通人最大的误区就是太想拥有所有权了。

往后至少还会有很多年，所有权将是我们最大的负债。

坚持轻资产，抛弃所有权，拥抱使用权，保持高流动性，再用钱生钱。
