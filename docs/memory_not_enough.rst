第三方NAND产品主控领域的领军企业群联Phison，其首席执行官潘建成在近期举行的2025年第三季度财报电话会议上，发表了一番引人注目的言论。他指出，当前由AI推理所驱动的存储市场行情极为特殊，不仅在其职业生涯中前所未见，甚至可能是一生仅遇一次的盛况。

群联在该季度的财务表现堪称亮眼。据财报显示，公司营收达到了181.37亿新台币，按照当前汇率换算，约为41.68亿元人民币，环比增长1.4%，这一数字不仅刷新了公司的历史记录，也彰显了其在市场中的强劲势头。同时，毛利润也攀升至58亿新台币，同样创下了历史新高。

面对市场供应紧张的局面，群联采取了谨慎的出货管理策略，并对新订单进行了严格控制，以确保所有订单都能顺利完成。与此同时，公司正积极调整供应资源，将更多的资源从消费级市场转向企业级、工业级、嵌入式以及ODM端市场，以满足这些领域日益增长的需求。

潘建成在会议中还透露，近期所有NAND闪存厂商都纷纷提价，涨幅惊人，高达50%至75%。以7月时1Tb TLC的价格为例，当时仅需约4.8美元，而到了11月初，这一价格已经飙升至10.7美元。这一涨价趋势预计将进一步推高第四季度的企业级需求。而在客户端市场，群联的主控出货量也呈现出爆发式增长，同比增长380%，环比增长72%。然而，台积电6nm产能的紧俏状况，却对未来的供应能力构成了一定的限制。

潘建成还就原厂NAND闪存业务的毛利率问题发表了看法。他表示，当前原厂NAND闪存业务的毛利率大约在50%至60%之间，这是一个相对合理的水平。然而，如果毛利率攀升至80%，则可能会对整个行业造成不利影响，甚至扼杀行业的创新与发展。因此，作为控制器企业的高管，他希望上游原厂能够保持理性，不要过于拉升出厂价格。当然，他也承认适度的涨价对于原厂新建产能、扩张供应是有积极作用的。
