潘建成是去年最早提出记忆体10年超级周期的业内人士，2023年ChatGPT 兴起的时候就说出会出现NAND Flash没有天花板的需求，也是最早提出NAND用于GPU运算系统的
前些天黄仁勋访谈中说基建至少还要持续7-8年，也就2035年前，和潘总说出的十年超级周期差不多
过去运算系统都是DRAM，现在NAND除了用于存储，还会进入运算系统，补DRAM的不足，黄仁勋2026CES发布会提到系统已经引入大量NAND，Ai转向推论需要大量的NAND，Rubin平台每个GPU旁边有22TB的SSD，假设英伟达年销量1000万颗GPU的SSD容量就是200EB，2025年全球总产出也就1000EB，占全球产量20%，英伟达2026年前5个月订单量就有2000万颗GPU，机构预计今年出货量1250万颗……这只是用在GPU运算端的需求，另外用在存储上的还没算，在存储方面对NAND的需求永无止境……NAND价格是DRAM的1/50，厂商都去做高利润的DRAM，导致NAND缺货比DRAM更严重，这辈子最严重的缺货……云端公司收入与存储成正比，存储需求没有天花板，所以不存在所谓的周期性了……
NAND Flash 现在扩产供需平衡需要2-3个周期，每个周期最快2年，采购荷兰设备要排队两年交货，扩产成本也会增长，但是过几年又会有新增的需求，缺口仍然存在……
现在 Flash有原厂要求预付3年的款，因为预判短缺至少3年
群联自己目前的产能只能满足客户3成的订单
大陆厂商扩产只会增加3-5%的产能，但缺口是10-20%，扩产速度也没那么快，目前记忆体的短缺都是云端造成的，地端未来的增量需求还是不能满足，而且大陆内部对记忆体的需求也短缺，自己不够用，所以不存在有低价外销的情况，提价最积极的第一家是美企，第二家就是陆企
