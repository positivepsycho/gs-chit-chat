随笔160 不要随便提醒别人
==============================

不要随便提醒别人，说深一点，未被邀请的建议本质上是一种冒犯。
---------------------------------------------------------------------------

真正通达的人都知道，与其把一个人叫醒，不如让他开心。

你以为你在帮他，他感受到的是被俯视，免费的提醒换不来感激，你对他的提醒只会让他感觉到你在彰显优越感，说白了你咋那么欠那？ 

你是不是很闲，很想被表扬。

如果要出主意，必须收费。

所谓的收费不是你的问题，而是让他先把诚意放在桌子上，然后你才有理由耗费心力。

没有这个前提，你说的越对，他对你恨意越深。

我的原则只有两个赞美或者沉默，这不是冷漠。这是我当年因为嘴欠毁掉多段关系之后留下的一点教训。
