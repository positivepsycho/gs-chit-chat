我们还是那句话：资产的价格在于共识。

飞天茅台都在跳水、批发价已经跌到指导价，而它的好搭档片仔癀早就跌破指导价了。

这其中的逻辑是：

高端商务场合需要飞天茅台，饮酒之后又有护肝需求，所以飞天茅台走上神坛，自然把护肝神药片仔癀也推到了天价。

**从经济学角度，对这种“好搭档”的关系，有一种更严谨的解释，那就是互补品的概念。**

如果两类商品互为互补品，那么它们的需求就会体现一定的关联性，当其中一类需求提升，另一类的需求也会水涨船高。而互补品关系还可以再分为两种，一种是强互补品，一方的功能实现严格依赖于另一方，往往必须同时使用；而一种是弱互补品，一方也能够有效提升对另一方的需求，但并不是绝对的依赖或者必需。

而高端酱香酒和高端护肝药，显然就是更隐蔽的弱互补品关系。高端酱香酒和高端护肝药都有各自的使用功能，并没有建立严格依赖，也没有必须同时使用的特征，这种弱护补品关系完全依赖于飞天茅台本身的“飞天”。

而现在这个前提本身已经皮之不存，好搭档自然是毛将焉附，近期以来飞天茅台价格持续快速下滑，而片仔癀的下滑还要更为明显——茅台是在近期才在零售价方面跌破指导价、在批发价方面挑战指导价，而片仔癀在零售渠道早就大幅跌破了指导价。

不过，片仔癀的下跌怪飞天茅台，飞天茅台的下跌又怪谁呢？

其实我们要认识到，这对好搭档先前走上神坛，并不是因为物质意义上的使用功能多么出色，而是显然有附加的外部因素。说白了，就是高速城镇化过程带来的大规模的工程建设，也带来了大量的政商宴请活动，带来了大量的酒桌。正是这种酒桌上被讨论的攸关对方利益的工程建设，才使得飞天茅台和片仔癀先后被赋予了金融属性。

所以现在两者都出现跳水的情况，就不能单纯归咎于其中一方的跳水，更不能从它们的使用功能上找原因，否则就会得出诸如“年轻人不爱喝酒”、“高端护肝药效果没那么神”等显著有偏差的结论，而是同样要从同样的逻辑上找原因——那就是大规模的城镇化过程趋于尾声，楼市也深度调整，使得实际上已经没有那么多工程建设可供在酒桌上推杯换盏了。

所以，飞天茅台也好、片仔癀也罢，它们的下跌，是金融属性显著削弱之后真正的价值回归，是市场逐渐高度趋同的共识——那就是大规模工程建设不会再有了，没有了工程，还会摆那么多酒桌、还需要那么多飞天茅台和片仔癀吗？

而且片仔癀不同于飞天茅台的另一个点，在于它的保质期更短、保存更困难，经销商合市场囤积居奇的动机更弱、更显得是望风而降。所以，只要飞天茅台站不起来，片仔癀就不可能会站起来。如果仅仅是从药品、健康的角度投资片仔癀，也要认识到它现在的价格根本不足以形成支撑。

对飞天茅台和片仔癀，接下来形成的将是深度调整竞赛，唯一的悬念只有从目前开始，谁将出现幅度更大、速度更快的调整。在市场上，理解共识的力量以及共识为何形成，永远要比理解单个投资者或机构的投资逻辑更重要。
