随笔212 为什么存储依然被低估
=========================================================

数据爆炸的时代，存储才是真正的刚需。
----------------------------------------------

AI就是新型军备竞赛，商业航天也是。
-----------------------------

AI的本质是啥？就是跑数据，就是把物理世界数字化。那么数据放在哪里，存储。
----------------------------------------------------------------------------


如果说AI有泡沫，一定不是存储。因为它其实刚刚开始进入到了一个长的缺货周期。

那这一波是因为AI的军备竞赛。

因为实际上AI到底是啥？它就是把一个物理的世界数字化。数字化就是数据啊，真正AI最后跑的是啥？就是跑数据啊，现在只是训练大模型刚出来，对吧？那真正推理今年是元年agent也好，推理也好，其实刚刚开始。

当我们每个人每个企业，每一个物体都在产生数据的时候，你想想那个数据量那是爆炸性的那绝对是指数级的那个存储的生产的周期是远远满足不了的。

你做一个新的工厂，大概要两年，你上一个生产线，然后还要上测试设备。测试设备它的生产速度是很慢的。一个Smail一年可能只能生产几十台。

我在一家工厂，现在光放测试设备。 一起步我要放15台，大概就是2000万。那你想想，如果是我的几倍的，光我们的测试设备，那是几十上百的那如果一个工厂要给很多人生产，就它是一个很复杂的供应链。

所以他不是说哦今天数据增长了，然后我立刻买设备上生产线，马上就能产，就跟做口罩可不一样，这个大概最快最快，我估计一年半，所以他这个缺口是确定的。

为什么只有那么几家公司做存储啊？做存储这个是一个重资产投入，可能是千亿级的投入，不是谁都能做的。你像中国现在就两家，一个长新，一个长存。那这么好的赛道，为啥不会像其他行业哇，像像车一样，对一下扎出100家，不可能千亿级的投入，

你投得起吗？这一定是国家级的。我担心的是，因为存储它是要存的这个对象有价值。

存储器才会有市场，接些数据不能变现的话，那么这个存储的故事还会像大家预料的一样，需要更多的存储器吗？不是说我们产生的所有数据都会存下来。比如说你自动驾驶的汽车。

你全程抓那么多数据，很多sensor是不可能全存的那后面云就爆了，我们的这些数据中心的客户痛点就是存储量。 如果说要都存下来，那太大了，太贵了，他没有办法全存。

当然未来如果有一个量子级的这种技术，那可能将来就一个更是一个颠覆式的。
