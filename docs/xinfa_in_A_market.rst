随笔235 心法
==============================================


把A股各流派揉碎了看，底层心法其实就这几条——所有游资、机构、量化反复验证过的共识。

🧭 择时：择时 > 选股

- 情绪周期是一切操作的地基。启动（冰点试错）→ 发酵（加仓主升）→ 高潮（减仓兑现）→ 退潮（空仓防守），周期对了操作才可能对。
- 退潮期空仓是最高级的操作。空仓不是放弃，是保存实力。
- 时机大于努力：行情好多做，行情差少做，没有好机会就保持观望，不强行交易。

🐉 选股：只做主线龙头

- 只做主线龙头，不做跟风杂毛。能带动板块的才叫龙头，一个主线题材通常只有一个总龙头。
- "新、大、强"三线筛选：新（全新政策/新技术/新产业）、大（板块容量够，几十只个股联动）、强（涨停≥5家，有清晰连板梯队）。
- 没有板块联动的独立个股，再低也不碰。

🔄 买卖：买在分歧，卖在一致

- 买点：龙头放量烂板、首次分歧但板块热度未退、回踩缩量企稳、分歧转一致 （弱转强）。
- 卖点：市场情绪极致一致（全网吹捧）、缩量加速一字板、板块鸡犬升天。
- 核心心法："买入机会，卖出风险"——不纠结止盈止损，只关注操作是否正确。

📐 仓位：赢面决定仓位

- 赢面＜60%：空仓观望
- 赢面60%-70%：轻仓试水
- 赢面70%-80%：中仓出击
- 赢面80%-90%：重仓参与
- 赢面＞90%：满仓出击
- 仓位是情绪周期的温度计，不是赌大小的筹码。

🛡️ 风控：纪律高于一切

- 铁律：3%-5%止损线无条件执行，绝不补仓绝不扛单。
- 连续亏损3天：强制空仓3天，从"扳本心态"中脱离。
- 单票仓位上限：游资普遍控制在7%-20%之间。
- 亏损绝不加仓：亏损说明判断可能出错，绝不摊平成本。

🧠 心态：战胜自己

- 忘记成本做决策：问自己一句——"如果现在空仓，我还会买它吗？"不愿就卖，愿意就留。
- 操作的对错与盈利无关：正确操作亏钱也是对，错误操作赚钱也是错。
- 警惕三个最危险时刻：踏空时、连续成功后、大亏后想扳本时。
- 高手大部分时间是空着的：高手的境界不是进攻，而是等待。

📊 大局观排序

政策面 ＞ 人气面 ＞ 资金面 ＞ 技术面 ＞ 基本面

- 交易本质是群体心理博弈，不必死磕K线指标。
- 做市场的跟随者，不主动预判行情发动，尊重市场给出的选择。
- 判断为末，应变为本：预测不重要，应对才重要。

⚡ 知行合一

- 盘前写好计划，盘中只执行不临时起意。
- 所有稳定盈利都是耐心等出来的，不是频繁做出来的。
- 拉开差距的是复盘：每天交易只有4小时，剩下的时间才是拉开差距的时候。
- 没有捷径：至少经历一轮牛熊，才会真正理解市场。

⸻

以上为A股各流派交易心法的归纳整理，不构成投资建议。股市有风险，入市需谨慎。
