随笔135 薛兆丰的经济学课基础（成本，边际，利息，博弈，靠谱）
================================================================

视频中薛兆丰提出的五个关键原理：

1.成本—放弃的最大代价；2.边际—关注增量而非总量；3.利息—时间创造价值；4.博弈—换位思考做决策；5.靠谱—建立长期信任。这些不是公式，而是帮孩子理解"选择"本质的生活智慧。

成本：放弃的最大代价  

本质是选择背后的隐性损失。比如选文科还是理科，真正成本不是学费，而是你放弃的另一条人生路径。难点在于人们总高估眼前可见的牺牲，却忽视看不见的可能性。  

实操：让孩子每天睡前复盘一个选择，问"我放弃了什么"；用零花钱做实验，选买玩具还是存钱，一个月后对比感受。

边际：聚焦未来的决策智慧  

不是算你已学6小时语文，而是问剩余时间如何分配能让总分最高。关键在当下可支配资源的最优配置，而非沉没成本。  

实操：周末给孩子3小时自由时间，引导规划各科复习比例；购物时讨论"再花100元能提升多少幸福感"。

时间：延迟满足的复利效应  

考试前一周复习vs考后复习效果天壤之别，正如织网捕鱼比徒手抓鱼收获更大。时间价值在于懂得等待优质回报。  

实操：设立"成长储蓄罐"，每天坚持的小事（如阅读）积累成月度奖励；用植物生长记录直观展示时间力量。

时间：延迟满足的复利效应  

时间是最稀缺资源，价值在于懂得等待优质回报。考试前一周复习vs考后复习效果天壤之别，正如织网捕鱼比徒手抓鱼收获更大。关键要让孩子理解：今天的忍耐会换来明天的倍增收益。  

实操：设立"成长储蓄罐"，每天坚持的小事（如阅读）积累成月度奖励；用植物生长记录直观展示时间力量；分析日常选择（如早睡vs熬夜）的长期影响。

博弈：预判他人的决策艺术  

博弈思维是把别人的想法考虑在内，理解社会互动是多方决策的结果。看到高价商品不骂商家贪心，而是理解"喜欢它的人太多"。真正的竞争力来自洞察他人需求，而非单方面索取。  

实操：玩桌游时分析对手策略；家庭会议中练习"如果我是爸爸会怎么想"的角色互换；引导孩子分析矛盾双方的真实需求，寻找共赢方案。

靠谱：人际信任的隐形货币  

靠谱是信息不对称社会中最珍贵的通行证，表现为守时、承诺必兑现。职场中80%的机会来自可靠口碑而非显性能力，每一次履约都在积累信用资产。  

实操：制作家庭守约积分表，履行承诺积星；让孩子负责每周采购清单，培养责任感；当孩子完成承诺时，明确肯定其带来的具体价值（如"因为你按时喂狗，全家能安心出游"）。
