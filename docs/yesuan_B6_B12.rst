随笔164 叶酸+B6+B12
=============================================================================

“适量补叶酸。”
-------------------------------------------------------

1. 什么是“H型高血压”？
 
定义：指高血压患者同时伴有 同型半胱氨酸 升高（通常大于10μmol/L）。

现状：我国约四分之三的高血压患者属于此类。

危害：高血压（水压高）加上高同型半胱氨酸（水中有沙子），会像砂纸一样反复磨损血管内壁，导致中风风险飙升至普通健康人的 12倍以上。
 
2. 为什么要补充叶酸？
 
降低同型半胱氨酸：叶酸是代谢同型半胱氨酸的关键原料。体内缺叶酸会导致同型半胱氨酸在血液中堆积。

预防中风：对于H型高血压患者，单纯控制血压可能不够，补充叶酸能显著降低脑卒中（中风）的风险。
 
3. 如何科学补充？
 
黄金剂量：每日补充 0.8毫克 是预防中风的黄金剂量。

补充方式：不能仅靠食补（食物中的叶酸利用率较低），通常需要通过药物或复合维生素补充。

搭配建议：建议搭配维生素B6和B12一起服用，效果更佳。
 
4. 建议检查
 
如果您是高血压患者，下次去医院复查时，除了测血压，建议加查一项 同型半胱氨酸 指标，以确定是否需要补充叶酸。
