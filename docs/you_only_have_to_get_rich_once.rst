随笔234 You only have to get rich once（一生只需富一次）
============================================

巴菲特1998佛罗里达大学商学院演讲核心（段永平反复推荐）

这场不是单向讲课，是**开场简短分享 + 学生问答**，最大特点：**先讲做人、再讲投资，投资是人品与思维方式的延伸**

一、开场最经典思想实验（全篇引子）

> 假设：你可以买下班里一位同学未来一生收入的10%；同时必须做空另一位同学未来收入的10%。
你不会单纯选智商最高、成绩最好的人，你会选：**靠谱、诚信、稳定、自律、善于合作、情绪稳定**的人；避开自私、爱耍小聪明、不守信用的人。

巴菲特由此引出用人标准：**诚信、头脑、精力。聪明勤奋但品行差的人，是祸害。**
结论：**习惯和品格决定长期收益，品格是可以主动塑造的**。你要刻意养成自己敬佩的品质，远离坏习惯。

配套金句：**只和自己喜欢、敬佩的人共事；哪怕能赚1亿，也不和讨厌的人合作，就像不能为了钱结婚**

二、投资核心原则（问答里反复讲，段永平重点吸收）

1. **能力圈（不懂不做）**
清楚自己懂什么、不懂什么，只在自己看得明白的领域出手；不必懂所有行业，不需要抓住每一个机会。投资不需要跨很高的栏，**只跨一英尺的栏**。

2. **买股票就是买公司，看护城河**
重点不是行业增长快不快、热不热门，而是**企业的竞争优势能不能持续（护城河）**。找未来很多年盈利能力很难被颠覆的生意。

3. **安全边际**
用显著低于内在价值的价格买入，给自己犯错留余地。

4. **长期持有**
如果你不愿意拿十年，十分钟都不要拿。追求可以拿很久的好生意，而不是频繁交易。

5. **一生只需富一次（You only have to get rich once）**
**不要加杠杆、不要冒致命风险**。亏钱很容易把之前所有积累清零；慢一点、稳一点，不要赌。这是段永平最看重的一句。

6. **简单、少决策**
不需要很多次聪明的操作，少数几次高质量的决定就足够；不需要过度分散。

三、对市场、宏观、预测的态度

- 不预测股市短期涨跌、不预测利率、不预测宏观经济；预测很难，对投资帮助很小。
- 市场是你的仆人，不是你的向导：市场有时候疯狂，你要利用它，而不是跟着它情绪走。
- 不要追逐热门题材、不要跟风去自己看不懂的风口。

四、人生与选择（和投资一体）
- 做自己热爱的事，而不是单纯为钱去做一份工作。
- 承认运气的巨大作用：很多成功来自运气，不要把一切归于自己能力。
- 评价标准：**你想成为什么样的人，就按那个标准去要求自己，而不是看别人怎么看你**。

五、几个高频被引用的原话
- 诚信、智力、精力，三样里缺诚信，别的越厉害越危险。
- 只跨一英尺的栏杆。
- You only have to get rich once（一生只需富一次）。
- 如果你不想持有十年，就不要持有十分钟。
- 不和自己不喜欢的人做生意。
